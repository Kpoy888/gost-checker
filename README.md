# Проверка оформления чертежа (СПДС / ЕСКД)

Бесплатная локальная программа для Linux. Она принимает строительный чертёж и **проверяет отдельные правила оформления** по СПДС и ЕСКД: формат и рамку, основную надпись, типы линий, шрифты, масштабы и размеры. Для DXF и DWG умеет **осторожно поправить** то, что безопасно: добавить рамку и штамп, если их нет, сдвинуть надписи и геометрию с наложением на штамп в рабочее поле листа, нормализовать толщины слоёв, округлить высоты текста, выставить размерный стиль с засечками.

Это учебный инструмент, в том числе для студента 1 курса СПбГАСУ (строительство уникальных зданий и сооружений, подземные сооружения), который работает в Renga, nanoCAD и Revit. **Программа не заменяет нормоконтроль и не приводит любой чертёж «ко всем ГОСТам».** В отчёте всегда написано, что именно проверялось.

Платные API не используются.

## Что умеет

| Формат | Что происходит |
| --- | --- |
| **DXF** | Полная проверка и, при `--fix`, безопасные исправления. На выходе — исправленный DXF и отчёт. |
| **DWG** | Конвертация в DXF бесплатным LibreDWG (`dwg2dxf`): программа ищет утилиты в `vendor/libredwg/bin`, в `PATH` и по `LIBREDWG_PREFIX`. Если их нет — запустите `scripts/install_dwg.sh` (соберёт официальный tarball GNU) либо установите пакет `libredwg-tools`. Запасной вариант — ODA File Converter. Запись обратно в DWG — через `dxf2dwg` (формат r2000) или ODA. |
| **PDF** | Только отчёт. Формат листа — по размеру страницы. Поля рамки 20/5/5/5 мм измеряются по осевой линии штриха: сначала векторные пути PyMuPDF (`get_drawings`), затем растр OpenCV с поправкой на половину толщины линии. Допуск ±0,5 мм. Tesseract (русский) читает штамп. Файл не изменяется. |
| **PNG / JPG** (скан, фото) | Только отчёт. Лист выравнивается (deskew), край и внутренняя рамка ищутся контурами. Если DPI неизвестен, масштаб выводится из пропорции обнаруженного листа и таблицы ГОСТ 2.301 (включая кратные форматы вроде А3×3). Поля сравниваются с 20/5/5/5 мм. OCR читает графы штампа по ячейкам. |
| **Renga** (`.rnp`, `.rnt`) и **Revit** (`.rvt` и родственные) | Прямого чтения нет. В отчёте — понятная просьба экспортировать вид в DXF/DWG (или IFC). |
| **IFC** | По желанию: краткие сведения о модели, если установлен `ifcopenshell`. Оформление листа не проверяется. |

## Какие правила проверяются

Каждое правило — отдельная проверка со своим кодом, ссылкой на ГОСТ, оценкой и флагом автоисправления.

1. **`sheet_frame` — ГОСТ 2.301-68**  
   Форматы А0–А4 и дополнительные (А3×3 и др.). Внешняя и внутренняя рамки ищутся даже если собраны из отдельных LINE, полилиний, блоков или лежат в пространстве листа. Каждое поле измеряется и сравнивается с 20/5/5/5 мм (±0,5 мм): в отчёте и на веб-странице есть таблица «факт / норма / сходимость». Если рамки нет, `--fix` добавляет выбранный формат (по умолчанию А3 альбом, для А4 — портрет). Существующую кривую рамку программа не двигает.

2. **`title_block` — ГОСТ Р 21.101-2020, форма 3 (185×55 мм)**  
   Ищет контур или блок основной надписи, читает графы (Разраб., Пров., Н.контр., обозначение…) из атрибутов или OCR по ячейкам и отмечает пустые обязательные поля. Также ищет дополнительные зоны слева и над штампом. Если штампа нет, `--fix` вставляет блок с графами. Сетка граф — практическая реконструкция характерных размеров формы 3, а не сертифицированная калька официального рисунка.

3. **`layout_overlap` — ГОСТ Р 21.101-2020 п. 5.2.1**  
   После добавления рамки и штампа ищет текст и геометрию, которые заехали на основную надпись. `--fix` сдвигает пересекающие штамп надписи (TEXT/MTEXT) вверх или влево; если пересекается и геометрия или чертёж не помещается в свободное поле над штампом — сдвигает и при необходимости пропорционально уменьшает всё содержимое модели (кроме рамки и штампа), сохраняя взаимное расположение. В отчёте перечислено, что именно сдвинуто.

4. **`linetypes` — ГОСТ 2.303-68**  
   Смотрит типы и толщины линий **на слоях**. Основная сплошная — S = 0,5…1,4 мм, тонкая — примерно S/3…S/2, плюс штриховая и штрихпунктирная. `--fix` создаёт стандартные слои (`SPDS_OSN`, `SPDS_TON`, `SPDS_OS`…) и округляет странные толщины слоёв к ряду 0,18; 0,25; 0,35; 0,5; 0,7; 1,0; 1,4; 2,0 мм. Объекты с ваших слоёв по умолчанию не переносятся. Опционально `--assign-layers` (только вместе с `--fix`) раскладывает объекты по слоям СПДС по эвристике: текст → `SPDS_TEXT`, размеры → `SPDS_DIM`, осевая / CENTER → `SPDS_OS`, штриховая → `SPDS_NEVID`, толстая линия → `SPDS_OSN`, иначе `SPDS_TON`.

5. **`lines` — ГОСТ 2.303-68, распознавание начертания**  
   Классифицирует линии: сплошная основная, сплошная тонкая, штриховая, штрихпунктирная (осевая), волнистая/с изломами. В DXF — по типу линии, весу, слою и шаблону; в векторном PDF — по толщине штриха и dash-массиву; на скане — по толщине (distance transform) и чередованию штрихов вдоль отрезков Хафа. Проверяются отношения тонкая = S/3…S/2 и длины штрихов (2–8 / 1–2 мм, осевая 5–30 мм). В `out/lines_overlay.png` рисуется цветная схема, в отчёте и веб-интерфейсе — сводка по типам.

6. **`fonts` — ГОСТ 2.304-81**  
   Стили должны использовать шрифт ГОСТ (например `GOST type A`, `ISOCPEUR`). Высоты — из ряда ГОСТ 2.304-81: 1,8; 2,5; 3,5; 5; 7; 10; 14; 20; 28; 40 мм, включая встроенные высоты MTEXT (`\\H`), TEXT без собственной высоты (из стиля) и размерный текст DIMTXT. `--fix` назначает стилю имя шрифта «GOST type A» и округляет высоту к ближайшему значению этого ряда (11 мм становится 10 мм, а не 7 мм). Сам файл `.shx`/`.ttf` в чертёж не встраивается: его нужно поставить в CAD.

7. **`scales` — ГОСТ 2.302-68**  
   Отчёт: видовые экраны, аннотативный масштаб, надписи вида `1:100` и оценка по сравнению размерного числа с фактической длиной геометрии (в пределах 8 % от ряда ГОСТ). Если надпись на штампе/листе и вывод из размеров расходятся, выдаётся замечание. Ничего не исправляет.

8. **`dimensions` — ГОСТ 2.307-68 и ГОСТ Р 21.101-2020 п. 5.4.2**  
   Для строительных чертежей линейную размерную линию ограничивают **засечками** 2–4 мм под 45°, а не стрелками. Стрелки остаются у радиусов, диаметров и углов (ГОСТ 2.307-68). Проверяются высота текста (не ниже 2,5 мм, ряд ГОСТ 2.304), выступ выносных (1–5 мм) и отступ от контура. `--fix` ставит засечки только линейным размерам и не затирает высоту, которая уже входит в ряд.

## Честно о границах

- Нельзя надёжно «взять любой чертёж и отдать его выполненным по всем ГОСТам». Особенно это касается сканов, фото и «сырых» моделей из Renga/Revit.
- Не проверяются содержание, комплектность, узлы, арматура, смысл примечаний и соответствие СП по конструктиву. Перенос на слои СПДС — только по явному флагу `--assign-layers` и только эвристикой.
- Рамку и штамп программа **добавляет**, если их нет. Если после этого содержимое наезжает на штамп, она сдвигает надписи или (если нужно) пропорционально вписывает модель в рабочее поле над штампом. Это не полноценная компоновка листа проектировщиком.
- Распознавание рамки может ошибиться на сложных чертежах, в дюймах или при единицах, отличных от мм.
- OCR на штампе ошибается на тонкой сетке и некачественных фото.
- DWG читается через LibreDWG. Если утилит ещё нет, запустите `scripts/install_dwg.sh`. У `ezdxf` своего читателя DWG нет. LibreDWG записывает DWG только в формате r2000; блоки с атрибутами и часть служебных таблиц могут пострадать, поэтому основным исправленным файлом остаётся DXF.

## Установка на Ubuntu / Debian

Нужны Python 3.10+ и, по желанию, системные пакеты для OCR и DWG.

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip \
    tesseract-ocr tesseract-ocr-rus \
    poppler-utils
# по возможности — свободный конвертер DWG из репозитория:
# sudo apt install -y libredwg-tools
# если пакета нет (часто так и есть) — собрать GNU LibreDWG:
# bash scripts/install_dwg.sh

cd gost-checker
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Необязательно:

- **LibreDWG** (`dwg2dxf`, `dxf2dwg`) — свободный конвертер DWG. Скрипт `scripts/install_dwg.sh` сначала ищет пакет `libredwg-tools`, затем скачивает официальный tarball GNU (по умолчанию 0.13.3) и ставит его в `vendor/libredwg`. Готовый каталог `vendor/libredwg` программа подхватывает сама. Если сборка невозможна, экспортируйте чертёж в DXF из nanoCAD / Renga / Revit.
- **ODA File Converter** — бесплатный (но не open-source) конвертер Open Design Alliance. Если он установлен и виден в `PATH` как `ODAFileConverter` или `odafileconverter`, программа его подхватит. Это запасной вариант, не обязательное условие.
- Шрифт **GOST type A** (или ISOCPEUR) в вашей CAD-программе, чтобы исправленные надписи выглядели как чертёжный шрифт, а не как замена системы.
- `pip install ifcopenshell` — только если хотите краткие сведения из IFC.

Проверка, что Tesseract видит русский язык:

```bash
tesseract --list-langs
# среди языков должны быть rus и eng
```

## Как запустить

Командная строка:

```bash
source .venv/bin/activate
python -m gost_checker путь/к/чертежу.dxf --fix --out out --titleblock samples/titleblock_example.json
```

Полезные ключи:

- `--fix` — внести безопасные исправления (только DXF/DWG);
- `--out КАТАЛОГ` — куда писать отчёт и исправленный файл;
- `--titleblock meta.json` — поля штампа (обозначение, наименование, стадия, лист, листов, разраб., организация…);
- `--format A3` — какой лист добавить, если рамка не найдена;
- `--render` — сохранить PNG-просмотр до/после;
- `--assign-layers` — перенести объекты на слои СПДС по эвристике (только вместе с `--fix`).

Пример JSON для штампа лежит в `samples/titleblock_example.json`.

Локальный веб-интерфейс (одна команда, страница на русском):

```bash
python -m gost_checker.web
# откройте http://127.0.0.1:7860
```

Публичный сайт без карты: запустите его на своём Linux-компьютере (`bash scripts/run_public.sh`). Скрипт сначала пробует Cloudflare Quick Tunnel (`https://….trycloudflare.com`, аккаунт не нужен), а если снаружи нет ответа — запасные туннели (localtunnel, Pinggy, serveo, localhost.run и др.). Адрес меняется при перезапуске туннеля. Подробности — в [`DEPLOY.md`](DEPLOY.md).

Облачные «бесплатные» хосты (Render, Hugging Face Docker/Gradio CPU Basic и др.) на ноябрь 2026 как правило просят карту или платный план. В репозитории по-прежнему есть `render.yaml` и `Dockerfile`, если облако вам подходит. Контейнер слушает `$PORT` или `7860`.

Можно также вызвать `python gost_check.py …` из корня проекта.

После проверки в каталоге `--out` появятся:

- `report.html`, `report.md`, `report.json` (в HTML есть таблица полей рамки, сводка линий и встроенные картинки);
- `lines_overlay.png` — цветная схема распознанных линий;
- `before.png` / `after.png` — если был `--render`;
- `имя_fixed.dxf` — если был `--fix` и вход был CAD;
- иногда `имя_fixed.dwg` — если доступен конвертер записи.

## Примеры и тесты

```bash
source .venv/bin/activate
python samples/generate.py          # samples/bad.dxf, samples/good.dxf, учебные PDF и samples/scan_demo.png
python -m gost_checker samples/bad.dxf --fix --out out --render --titleblock samples/titleblock_example.json
pytest -q
```

`samples/bad.dxf` намеренно «плохой»: без рамки и штампа, шрифт Arial, произвольные высоты текста, случайные слои и размерный стиль со стрелками. `samples/good.dxf` — более аккуратный учебный лист А3.

## Лицензии стандартов

Тексты ГОСТ здесь не воспроизводятся. Используются только общеизвестные числовые параметры оформления (размеры форматов, поля рамки, ряд высот шрифта, толщина основной линии и т.п.) и ссылки на номера документов.
