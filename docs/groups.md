# Группы функций

Группы для сайта и уведомлений в Telegram. У каждой функции одна основная группа. Группа «Слабые» — это не второй список тех же функций, а витрина: туда попадают только отложенные части, уже указанные в своих группах.

Разговорный чат-бот по ГОСТам (пункт 7) отменён и не делается. Поле «бот» в данных значит только канал уведомления о готовой проверке (пункт 3), не команды и не ответы на вопросы.

Статусы: `done` — уже в `main`; `in-progress` — код есть, но ещё не влит; `queued` — в очереди, кода нет; `deferred` — в очереди, но сознательно отложено.
